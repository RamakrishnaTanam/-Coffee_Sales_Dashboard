# ☕ Coffee Sales Dashboard | Microsoft Excel

An interactive **Coffee Sales Dashboard** built entirely in **Microsoft Excel** to analyze sales performance, customer behavior, and country-wise revenue. This project demonstrates the complete Excel analytics workflow—from raw data preparation to an interactive dashboard using Pivot Tables, Pivot Charts, Timelines, and Slicers.

---

![Coffee Sales Dashboard](Coffee%20sales%20Dashboard.png)

---

# 🎯 Business Problem

A coffee company wants to better understand its sales performance by answering questions such as:

- How are sales changing over time?
- Which country generates the highest revenue?
- Who are the top customers?
- Which roast type performs the best?
- Does customer loyalty influence sales?
- How do different coffee sizes impact revenue?

To answer these questions, an interactive Excel dashboard was developed.

# 🔄 Project Workflow

## 1️⃣ Data Collection

The project uses three datasets:

- Orders
- Customers
- Products

---

## 2️⃣ Data Preparation

Customer and product information were merged into the Orders dataset using:

- **XLOOKUP**
- **INDEX + MATCH**

These lookup functions enriched the sales data with customer and product details.

---

## 3️⃣ Data Cleaning

The dataset was cleaned by:

- Standardizing coffee names
- Cleaning roast type labels
- Formatting dates
- Formatting currency values
- Checking duplicate records
- Removing unnecessary inconsistencies

Functions used:

- `IF()`
- Number Formatting
- Date Formatting
- Remove Duplicates

---

## 4️⃣ Excel Tables

The cleaned datasets were converted into **Excel Tables** to enable:

- Dynamic ranges
- Automatic expansion
- Better Pivot Table integration

---

## 5️⃣ Data Analysis

Pivot Tables were created to analyze:

- Sales over time
- Sales by country
- Top customers

These Pivot Tables serve as the data source for the dashboard.

---

## 6️⃣ Dashboard Development

The dashboard combines:

- Pivot Charts
- Timeline
- Interactive Slicers
- Professional formatting
- Dynamic filtering

allowing users to explore the data from multiple perspectives.
